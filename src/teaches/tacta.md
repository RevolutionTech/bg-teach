# Tacta

### Overview
- [ ] Theme & vibe
- [ ] Objective: most visible dots of your color at end
- [ ] Game end: all players place all cards from their decks
- [ ] Each player has own color deck; keep as stack in hand

### Turn
- [ ] Never fan or look through deck; play either outermost card
- [ ] Lowest outermost card value goes first (TB: lowest combined value); clockwise
- [ ] First card connects to Starting Card
- [ ] Flip/rotate card freely before placing

### Placing
- [ ] Cover a matching shape on any card, any color
  - [ ] Shapes must align perfectly; outline underneath looks continuous
  - [ ] Dotted shape can cover hollow shape & vice versa
- [ ] Connect to only 1 card per turn (only 1 matching shape)
- [ ] Can't cross table edge
- [ ] No legal move = place card anywhere, touching nothing
- [ ] Can't move or rearrange placed cards
  - [ ] Nudge back into position if misaligned

### Illegal cards
- [ ] Remove if noticed, only if nothing placed on top
- [ ] Found at scoring: remove; dots it covered still count for owner

### Scoring
- [ ] Count own visible dots; player on right double-checks
- [ ] Ties share victory; or play again / first out wins
