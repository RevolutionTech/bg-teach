# Don't Go In There

### Overview
- [ ] Theme & vibe
- [ ] Objective: fewest Curses
- [ ] Game end: all Cursed Cards taken & all 3 Rooms removed

### Turn
- [ ] Place 1 Meeple on empty space in any Room
  - [ ] Higher space = earlier card pick but fewer Flashlights
- [ ] 3rd Meeple in Room → Haunt; take Planchette

### Haunt
- [ ] Roll Ghost Dice = dice icons on Room's 3 cards
- [ ] Each Meeple: Ghosts rolled − Flashlights on its space = Ghost Tokens
  - [ ] Ghost Tokens hidden behind screen
- [ ] Pick cards top Meeple → bottom; Meeple back to supply
  - [ ] Cards face-up by type
  - [ ] Check effect on taking card; "At Game End" waits
- [ ] Flip Room; deal 3 new cards
  - [ ] Deck empty → remove Room instead
- [ ] Next turn: left of Planchette holder

### Cursed Cards
- [ ] Dispel = flip face-down; Curses don't count
- [ ] Multiple sets can trigger again
- [ ] Each type's effect on card

### Scoring
- [ ] Resolve "At Game End" effects
- [ ] Sum face-up Curses
- [ ] Most Ghosts (incl. ties): +1 Curse per 2 Ghosts
- [ ] TB: fewer Ghosts
