# Deep Sea Adventure

### Overview
- [ ] Theme & vibe: rival divers share one sub + one tank of air
- [ ] Objective: most VPs after 3 dives
- [ ] Dive ends when air hits 0 or all Divers back on sub
- [ ] Push-your-luck: deeper = more VPs, but more risk

### Turn
- [ ] Skip turn if already back on sub
- [ ] 1. Breathe: air −1 per treasure carried
  - [ ] Only current-dive treasure counts
  - [ ] Air hits 0 → your turn is last of dive; finish it
- [ ] 2. Declare: turn back toward sub, or keep going
  - [ ] Need treasure to turn back
  - [ ] Once per dive; can't turn deeper again
  - [ ] Roll without declaring = go deeper
- [ ] 3. Swim: roll 2 dice, move that many chips in facing direction
  - [ ] −1 per treasure carried (can be 0 move)
  - [ ] Jump over chips occupied by other Divers w/o counting
  - [ ] Past last chip → stop on last chip
- [ ] 4. Treasure hunt: do nothing, OR pick up chip, OR drop treasure
  - [ ] Pick up: keep facedown, leave blank chip, Diver sits on blank
  - [ ] Drop: only on blank chip; any carried treasure
  - [ ] No limit on carried treasure

### Treasure
- [ ] 4 levels; deeper = higher values; values hidden until safe
- [ ] Return to sub once per dive; chips revealed and kept

### End of dive
- [ ] Safe Divers keep treasure
- [ ] Divers who didn't make it drop all treasure
  - [ ] Stack in groups of 3 at end of line; closest Diver to sub first, any order
  - [ ] Stack = 1 chip (pick up, drop, air, movement)
- [ ] Remove blanks; close gaps
- [ ] Air resets to 25
- [ ] Last Diver back on sub goes first next dive

### Game end
- [ ] After dive 3; total VPs
- [ ] TB: most high-level chips; else draw
