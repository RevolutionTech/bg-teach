# Fantastic Factories

### Overview
- [ ] Theme & vibe: build up your factory compound; dice = workers
- [ ] Objective: most points (goods + prestige)
- [ ] Game end: anyone has 12+ manufactured goods or 10+ cards in compound → finish round + 1 more
  - [ ] Prestige doesn't count toward either trigger
- [ ] Round: Market phase → Work phase

### Market Phase
- [ ] Turn order, clockwise from first player
- [ ] Optional first: pay 1 metal or 1 energy → replace all 4 blueprints OR all 4 contractors (once/turn)
- [ ] Then take a blueprint or hire a contractor → refill marketplace
- [ ] Blueprint: free, into hand
  - [ ] Marketplace only; no drawing from deck
- [ ] Contractor: discard blueprint matching tool above contractor → resolve + discard contractor
  - [ ] Some have an extra cost (top left)
  - [ ] Some also give an opponent of your choice a bonus
  - [ ] Tool tokens never move

### Work Phase
- [ ] Simultaneous (one at a time for first round or two if learning)
- [ ] Roll dice → build, place workers, activate cards in any order

### Building
- [ ] Pay metal/energy cost + discard *another* blueprint with same tool
- [ ] No build limit per turn
- [ ] No two cards with same name (unless card allows)

### Headquarters
- [ ] 3 slots per action
- [ ] Research (any value): draw 1 blueprint
- [ ] Generate (1–3): energy = die value
- [ ] Mine (4–6): 1 metal, regardless of value
- [ ] Matching values on same action: pair → +1 extra; triple → +2 extra
  - [ ] Dice needn't be placed at same time
- [ ] Work phase draws: top of deck only, never marketplace

### Activating Cards
- [ ] Pay left of arrow (resources, cards, dice) → gain right
- [ ] Once per card per turn (nudge card up to track)
- [ ] OK to activate same turn built
- [ ] Outputs usable immediately
- [ ] Each die used only once; leave dice placed when done
- [ ] Goods: keep on card that made them

### Card Types
- [ ] Production (blue): goods
- [ ] Utility (yellow): resources
- [ ] Training (red): change unplaced dice
  - [ ] No wrapping between 1 and 6 (±1 cards)
- [ ] Monument (grey): no activation; extra prestige
- [ ] Special (purple): unique effects
- [ ] Extra (white) dice: last 1 round

### End of Round
- [ ] Discard down to 12 resources (metal + energy combined) and 10 cards in hand
- [ ] Pass first player token clockwise
- [ ] Empty deck → reshuffle its discards
- [ ] Resources and dice unlimited

### Scoring
- [ ] Goods + prestige of cards in compound
- [ ] TBs: most metal, most energy, most blueprints in hand
